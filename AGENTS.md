# Repository Guidelines

## Project Structure & Module Organization
- `src/`: C++20 implementation (engine, UI, pieces). Entry point: `src/main.cpp`.
- `include/`: Public headers (e.g., `engine.h`, `bitboard.h`).
- `test/`: GoogleTest suite (`test.cpp`; add more `*.cpp` tests here).
- `piece_images/`: SDL2 assets used by the UI.
- `obj/`: Compiled object files (generated by `make`).
- `Makefile`: Builds `chess_app` and `chess_test` binaries.

## Build, Test, and Development Commands
- Build all: `make`
  - Produces `./chess_app` (GUI) and `./chess_test` (unit tests).
- Clean artifacts: `make clean`
- Run app: `./chess_app`
- Run tests: `export XDG_RUNTIME_DIR=/tmp && ./chess_test` (helps SDL on some systems).
- Note: GoogleTest lib path is set via `LDIRS` in `Makefile`. Update if your install differs (e.g., Homebrew path/version).

## Coding Style & Naming Conventions
- Language: C++20. Indentation: 4 spaces. Tabs not allowed.
- Braces on new line for functions/classes; K&R within control blocks is acceptable if matching existing files.
- Files: `lower_snake_case.cpp/.h`. Macros: `UPPER_SNAKE_CASE`. Types/classes: `PascalCase`. Functions/vars: `lower_snake_case`.
- No enforced formatter is configured; match surrounding style and headers includes order.

## Testing Guidelines
- Framework: GoogleTest. Place tests in `test/*.cpp`.
- Conventions: Use `TEST`/`TEST_F` with descriptive names, e.g., `TEST_F(ChessAppTest, MakeChessMove)`.
- Keep tests deterministic; mock randomness or bound it. Ensure SDL init succeeds where needed.
- Run locally with `./chess_test`; aim to keep coverage high for move generation and undo paths.

## Commit & Pull Request Guidelines
- Commits: Use imperative, concise subjects (<= 72 chars), e.g., `Optimize move generation using bitboards`. Include rationale and noteworthy tradeoffs in body.
- PRs: Provide summary, motivation, key changes, and test coverage. Link issues, attach screenshots/GIFs for UI changes, and list manual steps to verify (app + tests).

## Security & Configuration Tips
- Run from repo root so assets in `piece_images/` resolve.
- SDL2 and SDL2_ttf must be installed. If tests fail to link, adjust `LDIRS` and ensure `-lgtest -lgtest_main` are available.
